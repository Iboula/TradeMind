# TradeMind v1.0.0-core

## TradeMind v1.0.0-core - Deterministic Trading Intelligence Core

This release closes the V1 core platform foundation. It provides a bounded,
explainable and deterministic analytical pipeline. It does not include live
broker execution.

## Analytical pipeline

```mermaid
flowchart LR
    Market[Market Connectors]
    Context[Market Context]
    Agents[Expert Agents]
    Dispatcher[Expert Dispatcher]
    Consensus[Consensus Engine]
    Decision[Trading Decision Engine]
    Risk[Risk Engine]
    Plan[Trading Plan Generator]
    Workspace[Trading Workspace]
    Assistant[Trading Assistant]
    Paper[Paper Trading]

    Market --> Context --> Agents --> Dispatcher --> Consensus --> Decision
    Decision --> Risk --> Plan --> Workspace
    Workspace --> Assistant
    Workspace --> Paper
    Plan --> Paper
```

The pipeline keeps each stage explicit. The Trading Assistant consumes only
`TradingWorkspaceResult`. Paper Trading consumes only `TradingWorkspaceResult`,
`TradingPlanResult`, and explicit simulated market events.

## Architectural principles

- .NET 9 modular monolith with DDD bounded modules.
- Clean Architecture dependency direction: domain rules remain independent of
  infrastructure and external providers.
- CQRS-oriented application boundaries with explicit command and query paths.
- Immutable, versioned record contracts at module boundaries.
- Deterministic algorithms, stable ordering, explicit policies, and structured
  results instead of hidden side effects.
- Provider-agnostic AI abstractions; no concrete LLM SDK is required by core
  business modules.
- PostgreSQL, EF Core, pgvector, Docker, and Testcontainers remain adapters at
  the infrastructure boundary.
- No static service locator, global lock, or mutable shared state.

## Modules delivered

- Market Connector abstractions and PostgreSQL-backed Market Connector Core.
- KnowledgeHub ingestion, PostgreSQL persistence, pgvector cosine search, and
  HNSW indexing.
- Market Context Engine with parallel providers, freshness, quality, source
  traces, bounds, cancellation, and timeout policies.
- Expert Agent SDK with compatibility, authorization, versioning, validation,
  structured observations, evidence, scenarios, and warnings.
- Expert Dispatcher with intent classification, candidate discovery,
  relevance, deterministic version selection, Required/Preferred/Optional
  policies, budgets, fallback, and bounded execution.
- Consensus Engine and Trading Decision Engine.
- Risk Engine and Trading Plan Generator.
- Trading Workspace and explainable Trading Assistant.
- Deterministic Paper Trading simulation with orders, fills, SL/TP handling,
  realized and unrealized PnL, equity curve, journal, statistics, timeline,
  and replay fingerprints.
- Trading Journal Analytics and Coaching foundations.

## Deterministic processing guarantees

- Immutable and versioned inputs and outputs.
- Deterministic provider, agent, scenario, level, and result ordering.
- Explicit `TimeProvider` usage for time-dependent decisions.
- Explicit cancellation and per-operation timeout propagation.
- Bounded context, agent, dispatch, decision, plan, and paper-trading outputs.
- Stable truncation and stable replay fingerprints.
- No invented market levels, entries, stops, targets, or risk values.
- Critical conflicts and missing data remain visible in structured results.
- Paper Trading is simulation only and has no broker side effects.

## Paper Trading limitations

Paper Trading is a deterministic research simulator, not a broker emulator or
a production execution system. It does not connect to MT5 or another broker,
submit live orders, model a real account, guarantee fills, model every market
microstructure effect, or provide financial advice. Its event stream and
execution assumptions must be made explicit when comparing simulations.

## Known issue

Under high parallel test load, a pre-existing Coaching test can intermittently
hit a `RegexMatchTimeoutException` in the Coaching safety policy. This is not a
Sprint 23 regression: the full suite passes sequentially, and the affected
Coaching tests pass when isolated. The timeout behavior remains visible rather
than being disabled or hidden by the CI checks.

## Scope boundary

No live broker execution is included in V1.0.0-core. No MT5 adapter, order
router, account connection, or live trading side effect is part of this release.
