# TradeMind Trading Assistant

Deterministic, explainable and non-executable assistant built on top of `TradingWorkspaceResult`.

## Scope

- deterministic intent classification;
- structured localized answers (`en` / `fr`);
- declarative recommendations;
- workspace trace citations;
- safety disclaimer;
- structured logging and dependency injection;
- no LLM provider, broker, HTTP API, UI or persistence.
